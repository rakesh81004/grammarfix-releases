# Grammar Fix releases

APK downloads for **Grammar Fix**, an Android app that fixes the grammar of text you select in any app and suggests 3 alternative versions in the same tone.

**Install:** open [the latest release](../../releases/latest) on your phone, download `GrammarFix.apk` and open it. Android asks you to allow installs from your browser the first time.

**Update:** once installed, the app checks this page by itself and shows an "Update" prompt when a new version is out.

This repo holds release files only, not source code.
